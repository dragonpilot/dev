# dashy

The Python backend (`dashyd.py`, `serverd.py`, `dashy_server/`) is source and is edited here.

`web/dist/` is a **build artifact** generated by the separate `dashy-web` repo
and must never be hand-edited.

To change the UI, edit `dashy-web` and run its `deploy.sh`, which copies the built bundle here.

Tests live in `tests/` and run via `tools/test_runner.py dragonpilot/dashy/tests/`.
